中国大学MOOC 刷课助手 · 数据结构与算法（西安邮电大学）
==========================================================

【这是什么】
一个双击就能跑的小工具，自动完成这门课的：
  · 课件视频     自动拖到结尾（平台判定看完）
  · PDF 文档     自动逐页翻完
  · 讨论区       复制评论区已有回复发一条
  · 随堂测验     内置 49 套答案，答错会自动纠正
  · 单元测验/在线练习   内置题库，命中率不够会跳过以保护次数
  · 单元作业     内置完整答案全文，直接填入提交

已过期的项目（在线练习1/2、单元作业1/2）自动跳过，不浪费答题次数。
运行过程不需要联网 AI、不需要任何人协助，纯本地脚本。

----------------------------------------------------------
【第一次使用：三步】
----------------------------------------------------------
1) 拿到文件（不用装 Git）
   打开仓库页面 https://github.com/CYQ111999/mooc-shuake-assistant
   点右上角绿色「< > 代码」按钮 → 最下面点「下载 ZIP」
   解压到任意英文路径，比如 D:\mooc-shuake-assistant
   （别放桌面、别放中文目录）

   解压后如果双击 .bat 被系统拦住：
   右键 ZIP → 属性 → 最下面勾「解除锁定」→ 确定，再解压一次；
   提示「已保护你的电脑」时点“更多信息 → 仍要运行”。

2) 电脑上要有 Python 3.9 或更高版本
   没有的话去 https://www.python.org/downloads/ 下载安装，
   安装界面务必勾选 “Add python.exe to PATH”，然后重启本文件夹。

3) 双击「一键开始.bat」
   首次运行会自动创建环境并安装依赖，约 1~3 分钟（需要联网）。
   第二次以后基本秒开。

   弹出的浏览器窗口里登录中国大学MOOC（扫码或账号密码都行）
   ——只需要登录这一次，登录态会保存在 .profile 文件夹里。
   登录完成后脚本自动开始，不用回来点任何按钮。

最后在窗口里按菜单选「1 一键全自动」，然后就可以去干别的了。

【答题次数是怎么保护的】
----------------------------------------------------------
· 单元测验/练习只有 2~3 次机会：脚本只在“题库命中率 ≥ 50%”时才提交，
  命中率不够就跳过并提示（加 --force 可强制提交）。
· 提交后会从成绩页自动读取「正确答案」并存入
  data/learned_answers.json；如果还有剩余次数且没满分，
  会自动用学到的答案再考一次（平台取最高分，越考越准）。
· 想更保守：双击后在命令窗口输入  一键开始.bat all --min-cov 0.9
· 只想看效果不提交：加 --dry

【命令行用法（可选）】
----------------------------------------------------------
  一键开始.bat all              全自动
  一键开始.bat cw               只刷课件
  一键开始.bat assess           只做测验作业
  一键开始.bat check            只看进度
  一键开始.bat all --no-redo    测验只做一次，不重考
  一键开始.bat all --dry        演练：只填写，不提交
  一键开始.bat cw --max 20      本次最多处理 20 个课件

【常见问题】
----------------------------------------------------------
Q：报错 failed to create venv，或者 Unable to create process
   using 'C:\...\python.exe -m venv .venv'？
A：这是最常见的一个报错，不是工具的问题，是你电脑上的 Python 坏了。
   py 启动器还在，但它指向的 python.exe 已经不存在（安装没装完、卸载
   没卸干净、或者装的是微软商店版）。

   解决（3 分钟）：
     1. 打开 https://www.python.org/downloads/
     2. 下载 Windows installer (64-bit) 的 Python 3.12
     3. 运行安装包，务必勾选底部的 “Add python.exe to PATH”
     4. 关掉黑窗口，重新双击「一键开始.bat」

   不要用微软商店里的 Python；也建议避开 Python 3.14。
   v1.1 版启动器会自动跳过坏掉的 py、去找真正能用的 Python，
   找不到时会直接把这段指引打印出来并打开下载页。

Q：双击闪退 / 提示没有 Python？
A：装 Python 时勾上 “Add python.exe to PATH”，重开「一键开始.bat」。

Q：提示 “Target page, context or browser has been closed”？
A：上次的浏览器没关干净，把残留的自动化浏览器窗口全关掉再运行。

Q：讨论区提示“今日回帖数已达上限”？
A：平台每天限制回帖数量，第二天再运行一次，剩下几个会自动补齐。

Q：总成绩还是 0？
A：正常。总成绩要等学期结束、作业互评完成后才公布。工具只负责把
   该做的都做完，进度条满了就是满了。

Q：作业提交完还要做什么？
A：作业截止后会开放「学生互评」，必须你本人去评别人的作业，
   不参与互评会直接影响这份作业的成绩。这一步工具做不了，记得去点。

Q：中途关掉会怎样？
A：没有任何影响。脚本按平台的真实完成状态工作，下次运行会接着做剩下的。
