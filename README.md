# MOOC 刷课助手 · 数据结构与算法（西安邮电大学）

双击即用的小工具，自动完成中国大学 MOOC 这门课的**课件 + 随堂测验 + 单元测验/在线练习 + 单元作业**。

运行过程**不依赖任何 AI、不需要联网请求外部接口**，纯本地 Python + 浏览器自动化。

> 仅供同班同学学习辅助使用，请自行评估风险。

## 一、下载 & 运行（三步）

### 1. 下载 ZIP（不用装 Git）

1. 打开本页 → 点右上角绿色 **`< > 代码`** 按钮
2. 弹出菜单最下面点 **`下载 ZIP`**
3. 解压到任意**英文路径**，比如 `D:\mooc-shuake-assistant`（别放桌面、别放中文目录）

解压后目录里应该直接看到 `一键开始.bat`、`main.py`、`moocbot`、`data`。

> 会 Git 的话也可以 `git clone https://github.com/CYQ111999/mooc-shuake-assistant.git`，效果一样。

**解压后 .bat 打不开 / 被系统拦住？**
右键 ZIP 文件 → 属性 → 最下面勾上「解除锁定」→ 确定，再解压一次；
已经解压过的话，右键 `一键开始.bat` → 属性 → 勾「解除锁定」。
Windows 提示"已保护你的电脑"就点 **更多信息 → 仍要运行**。

### 2. 确认有 Python

需要 **Python 3.9+**。没有的话去 <https://www.python.org/downloads/> 装，
⚠️ 安装界面**务必勾选** `Add python.exe to PATH`。

### 3. 双击 `一键开始.bat`

- 首次运行会自动建虚拟环境 + 装依赖，约 **1~3 分钟**（需联网）
- 之后每次启动基本秒开
- 弹出的浏览器里**登录一次**中国大学 MOOC（扫码/账号密码都行）
- 回到窗口按 **`1`**（一键全自动），剩下的它自己干

登录态存在 `.profile` 文件夹，下次不用再登。

## 二、菜单说明

| 输入 | 作用 |
|---|---|
| `1` | 一键全自动：课件 + 测验作业 全刷 ← 推荐 |
| `2` | 只刷课件：视频 / 文档 / 讨论 / 随堂测验 |
| `3` | 只做测验作业：单元测验 / 在线练习 / 单元作业 |
| `4` | 只看进度，不改动任何东西 |
| `0` | 退出 |

命令行也能直接跑：

```bash
一键开始.bat all              全自动
一键开始.bat cw               只刷课件
一键开始.bat assess           只做测验作业
一键开始.bat check            只看进度
一键开始.bat all --no-redo    测验只做一次，不重考
一键开始.bat all --dry        演练：只填写不提交
一键开始.bat cw --max 20      本次最多处理 20 个课件
一键开始.bat all --min-cov 0.9  更保守：题库命中率要到 90% 才提交
```

## 四、答题次数是怎么保护的（重点）

单元测验只有 2~3 次机会，脚本做了这些保护：

- **命中率 < 50% 就不提交**，跳过并提示，不烧次数
- 次数已用完 / 已满分 → 直接跳过
- 作业进页面看到「已完成并提交」→ 跳过，不重复交
- 想重考提分时，要求「从成绩页学到的答案覆盖率 ≥ 90%」才动第二次，否则保留机会
- 交完自动读成绩页的「正确答案」存进 `data/learned_answers.json`，越跑越准

## 六、常见问题

### ⚠️ 报错 `failed to create venv` / `Unable to create process using '...python.exe...'`

这是**最常见**的一个报错，不是工具的问题，是你电脑上 Python 的安装坏了。典型长这样：

```
[1/3] Python found: py -3
      creating local virtual environment ...
Unable to create process using 'C:\Users\xxx\AppData\Local\Python\pythoncore-3.14-64\python.exe -m venv .venv'
[ERROR] failed to create venv
```

原因：`py` 这个启动器还在，但它指向的 `python.exe` 已经不存在了（安装没装完、卸载没卸干净、或者装的是微软商店版）。

**解决（3 分钟）：**

1. 打开 <https://www.python.org/downloads/>，下载 **Windows installer (64-bit)** 的 **Python 3.12**
2. 运行安装包，**务必勾选底部的 `Add python.exe to PATH`**，其他一路下一步
3. 关掉黑窗口，重新双击 `一键开始.bat`

> 不要用微软商店（Microsoft Store）里的 Python，`venv` 经常出问题。
> 也建议避开 Python 3.14 —— 部分依赖包还没跟上。

v1.1 起启动器会自动跳过坏掉的 `py`、去找真正能用的 Python，找不到时直接打印上面这段指引并自动打开下载页。

### 其他问题

**还没登录，但网页一直在刷新 / 跳来跳去**
v1.2 已修：未登录时程序会**停在登录页不动**，等你扫码或输密码，不会再自动刷新。
如果你看到过这个现象，重新下载最新版即可。

**浏览器里显示「立即参加 / 加入课程」**
说明这门课还没加入。点它加入，然后按一下黑窗口里的【回车】，程序会立刻重新检查。

**双击闪退 / 说没 Python**
装 Python 时勾上 `Add python.exe to PATH`，然后重新双击。

**提示 `Target page, context or browser has been closed`**
上次的自动化浏览器没关干净，把残留窗口全关掉再跑。

**讨论区提示「今日回帖数已达上限」**
平台每日限流，第二天再跑一次，剩下的会自动补齐。

**总成绩还是 0**
正常。要等学期结束、互评完成后才公布。工具只负责把该做的做完。

**作业提交完还要做什么**
作业截止后开放「学生互评」，**必须本人去评**，不参与会直接影响这份作业成绩，工具做不了这一步。

**中途关掉会怎样**
没影响。脚本按平台真实完成状态工作，下次接着做剩下的。
